# 90 Days DevOps Learning Plan

## Current Level
I currently work in IT and have hands-on experience with AWS cloud projects, networking fundamentals, Linux basics, DNS, VPNs, IAM, and internal workflow automation. I have also deployed real-world projects using Aws, Netlify, Google OAuth, and cloud-based integrations.

## Why I Am Learning DevOps & Cloud
I want to transition into a Cloud/DevOps Engineering role and build production-level infrastructure and automation skills. My goal is to combine my networking knowledge with cloud and DevOps technologies to become a strong infrastructure engineer capable of designing, deploying, automating, and troubleshooting modern systems.

## 90-Day Goals

1. Build strong Linux, Docker, and CI/CD fundamentals
2. Learn Infrastructure as Code using Terraform
3. Deploy and manage containerized applications using Kubernetes and AWS

## Core Skills I Want To Build

- Linux troubleshooting and system administration
- CI/CD pipeline automation
- Kubernetes deployment and debugging

## Weekly Time Commitment

- Weekdays: 2–3 hours daily
- Weekends: 5–6 hours daily focused on labs and projects

## My Execution Plan

- Stay consistent every day, even if progress is small
- Focus more on hands-on labs and projects instead of only watching tutorials
- Continue documenting projects on GitHub and LinkedIn
- Build real-world infrastructure projects to strengthen troubleshooting and deployment skills
- Practice cloud, networking, and DevOps together instead of learning tools in isolation

## Long-Term Goal

My long-term goal is to work as a Cloud/DevOps Engineer in NYC and become highly skilled in cloud infrastructure, automation, networking, security, and scalable system design.
